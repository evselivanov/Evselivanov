# Контекст проекта: уникальные монеты на CEX по сетям

Задача: считать количество УНИКАЛЬНЫХ монет на CEX-биржах по сетям (блокчейнам).
Критерий учёта монеты: на бирже открыт ДЕПОЗИТ в этой сети И идут спотовые ТОРГИ.
Источник данных — кошельковые/публичные API бирж (не веб).

## Метод уникальности

Дедупликация внутри каждой сети по двум ключам — адрес контракта (где биржа его
отдаёт) И тикер. Монета считается новой, только если ни контракт, ни (сеть+тикер)
раньше не встречались. Сети нормализуются по таблице синонимов
(ETH/ERC20/Ethereum → ETH и т.д.), чтобы одна сеть не двоилась.

Каскадный порядок учёта (кто раньше — тот застолбил монету):
Binance → MEXC → Gate → Bybit → HTX → KuCoin → BingX → Bitget → CoinEx → Bitmart → XT.

## Последний результат (11 бирж, замер 27.07.2026)

**4417 уникальных монет в 582 сетях.**

Топ сетей: ETH 1196, BSC 792, ARBITRUM 640, SOL 357, BASE 189, MATIC 104,
TON 43, TRX 36, MANTLE 34, SUI 32.

Особые строки в учёте: FIATMONEY (9, фиат Binance) и ROBINHOOD (18,
токенизированные акции MEXC) — оставлены в подсчёте намеренно.
Премаркет Gate (сеть ITSNOTACHAIN, 60 шт.) — ИСКЛЮЧЁН из подсчёта.

## Покрытие контрактами

По каждой бирже проверено, что API отдаёт КОНТРАКТ+ЦЕНУ+ДЕПОЗИТ: подходят 9 из 11
(у CoinEx и XT контрактов в API нет, 0%). Покрытие контрактами у остальных 79–90%
(недостающее — нативные монеты без контракта: BTC, TON, SOL и т.п.).

## Кандидаты на добавление (все три условия выполняют)

- **Coinbase Exchange** (api.exchange.coinbase.com) — 499 монет, контракты есть
- **Poloniex** (api.poloniex.com) — 1102 монеты, 1036 контрактов (лучшее покрытие)
- **Backpack** (api.backpack.exchange) — 7236 записей, 6491 контракт; уклон в
  крипту Solana, но есть токенизированные акции xStocks (TSLAx и т.п. — реальные
  SPL-токены с контрактом, депонируемые)
- **WEEX** (api-spot.weex.com) — контракты частично (488)

Не подходят (контрактов в API нет): OKX, Kraken, Upbit, Crypto.com, Bithumb,
LBank, CoinW, Bitrue, Toobit, BigONE, WhiteBIT, DigiFinex, Bitfinex, Gemini,
Bitstamp и др. ProBit — блок 403.

## Окружение

Старая сессия была без интернета — всё считалось через a-Shell mini на айфоне.
Новая сессия — "All Internet": запросы к API бирж делаются из облака напрямую.
У Binance и, возможно, MEXC вероятен блок 451 по US-IP — кто ответит из облака,
считаем в облаке; кто откажет — для тех остаётся телефон.

## Инструменты

Скрипт `all6` (11 бирж + логика + синонимы сетей) пишет отчёты в report.txt,
networks.csv, report.html (таблица сеть × биржа). Ключи бирж задаются через
переменные окружения (старые пары надо перевыпустить — они светились в переписке).

## Тест доступности из облака (29.07.2026)

Работают (HTTP 200): MEXC, Gate, HTX, KuCoin, BingX, Bitget, CoinEx, Bitmart, XT,
Coinbase, Poloniex, Backpack, WEEX — 13 из 15.

Гео-блок (считать через телефон): Binance (451), Bybit (403, CloudFront
«block access from your country» — UA и запасной домен api.bytick.com не помогают).
