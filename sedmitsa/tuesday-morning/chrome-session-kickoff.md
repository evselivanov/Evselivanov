# Промт для сессии с мостом в Chrome (Этап 1 ранбука Suno)

Вставить в новую сессию Claude Code на компьютере автора (с подключённым расширением
Claude в Chrome, вкладка suno.com залогинена). Самодостаточен: контекст истории не нужен.
Источник: sedmitsa/tuesday-morning/suno-runbook.md (Этап 1).

---

Подключись к моему Chrome. Открой suno.com (я залогинен, аккаунт lessve).
Правила: тексты вставлять ДОСЛОВНО, ничего не менять и не сокращать; «Instrumental»
должна быть ВЫКЛЮЧЕНА; чипы-подсказки под полем Styles не нажимать; ПЕРЕД каждым
запуском генерации (тратой кредитов) — остановись и спроси у меня подтверждение.

Задача:
1. Library → найти трек «Пока не зайдёт солнце полный 1» (6:43) → Remix/Edit → Extend.
2. Точка продолжения: конец последней СПЕТОЙ фразы. Прослушать последние ~40 сек;
   ожидаемо это пауза после «...и о цАрстве небЕсном — не позабОтился» (~6:2x).
   Точку ставить в паузе после фразы, не на слове.
3. В Lyrics для продолжения вставить дословно БЛОК A (ниже). Если трек оборвался
   раньше и бридж «чтО же сотворЮ...» тоже не спет — сказать автору, он даст
   дополнительный текст.
4. Styles не трогать (наследуется). После подтверждения автора создать 2–3 варианта.
5. Показать варианты автору; после выбора — Get Whole Song → скачать MP3
   с именем «Пока не зайдёт солнце I ПОЛНАЯ».
