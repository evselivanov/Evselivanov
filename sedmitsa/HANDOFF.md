# ДОСЬЕ ПРОЕКТА «СЕДМИЦА» — передача контекста новой сессии
Обновлено: 2026-08-04. Ветка: `claude/hit-analysis-vocals-melody-8r658u`.
Новая сессия: начни с этого файла, потом смотри файлы в `sedmitsa/tuesday-morning/`.

## Суть проекта

Музыкальный цикл «Седмица» по молитвам Кирилла Туровского (XII в.): каждый день недели — трек
в своём стиле, подобранном под вкус автора (список избранного ~3000 треков проанализирован).
Генерация — Suno v5.5. Язык — русский, тексты — современный перевод молитв, БЕЗ СОКРАЩЕНИЙ
(жёсткое требование автора, история: ассистент однажды сократил текст молитвы — это ошибка,
больше никогда; любое изменение текста только с явного согласия автора).

## Текущий этап: Вторник утро (молитва Иоанну Предтече + Христу)

Диптих «Пока не зайдёт солнце» в 2 частях (полный текст не влезает в один трек: лимит лирики
5000 симв., лимит длительности ~8 мин):
- Часть I — обращение к Иоанну Предтече (текст 4821 симв. с разметкой);
- Часть II — обращение ко Христу (текст ~3400 симв.);
- Шов по авторской архитектуре молитвы; общий припев-рефрен (форма акафиста);
- Кода I («вот день, которого мы ждали») и интро II («не дай меня бесам в радость») — сцепка.

## Звуковой рецепт (выстрадан итерациями, НЕ менять без причины)

Dark 90s Bristol trip-hop (реф: Tricky «The Only Way»), 68-72 BPM, ля минор.
Усталый тихий мужской покаянный голос, полуречитатив (НЕ хриплый «героиновый» — исправляли).
Припев: низкий чант по битам с шёпотным эхом в скобках, виолончельный рифф-ответ из 3 нот,
один подъём голоса на последней строке. Акустическая гитара (нейлон, одиночные ноты; электро
запрещена), одна виолончель (не секция!), сдержанный тянущийся бас с мягкой атакой (НЕ стаккато
«тум-тум» — исправляли), пыльные приглушённые ударные, виниловый треск. Тишина как инструмент:
провалы перед припевами, stop-time на ключевой строке хука. Куплеты на дроне, припев —
андалузская каденция Am-G-F-E (НЕ золотая секвенция и НЕ ось I-V-vi-IV — уводят в балладу,
пробовали, автор забраковал). Женский вокал ЗАПРЕЩЁН. Рояль/скрипка/оркестр запрещены.
Растяжки гласных (тьмЫ-Ы-Ы) НЕ работают — голос не тянет, убраны.

## Разметка текста (система)

ЗАГЛАВНАЯ гласная = ударение; « — » = цезура в долю; «...» = пауза-вдох;
«сло-ги-через-дефис» = чеканка по битам; растяжек гласных НЕТ.
Выверенные ударения: бЕды, нЕмощный, ослепленЫ, спасенА, трАпезы (были ошибки, исправлены).

## Настройки Suno (проверенные)

v5.5 Advanced. Персона «утро вторник в продакшн» (из трека B «ПокаЯние хорошая похожа»).

Style-поле и исключения: см. track-pokayanie-settings.md (лимит поля 1000 симв., наш - 973).

## Анализ аудио (методика есть, librosa)

Метрики хитовости: первый пик энергии до ~45 с; спектральный баланс (саб <80Гц не более ~35%,
середина 250-2000 Гц >13% — читаемость голоса); паузы >0.4 с (дыхание); контраст динамики;
регулярность громких секций. Сравнение трёх дублей — в track-A-hit-candidate.md.
Проверка полноты текста: нормализация (убрать теги/скобки/дефисы/растяжки, схлопнуть регистр)
и сверка мультимножеств слов с эталоном — скрипт в истории, легко воспроизвести.

## Правила работы (важно для новой сессии)

1. Текст молитвы неприкосновенен. Сокращение = серьёзная ошибка. Любая правка — только по
   явному запросу автора. После генерации сверять полноту автоматически.
2. Автор общается по-русски, кратко; решения принимает сам, предлагать варианты с рекомендацией.
3. Всё сохранять в репозиторий сразу (настройки, тексты, решения) — сессии эфемерны.
4. Присланные mp3 анализировать программно (librosa, pip install в сессии), давать вердикт цифрами.
5. Файлы >30 МБ в чат не влезают — просить MP3, не WAV.
